# 🐍 SnakeGame.pk

The classic **Snake game** in your browser — eat, grow, and don't crash!

## ✨ Features
- ⌨️ Keyboard controls (Arrow keys / WASD) + 📱 mobile D-pad
- 🏆 High score saved in your browser (localStorage)
- ⚡ Speed increases as you score
- ⏸️ Pause with SPACE
- Pure Canvas + JavaScript, no libraries
